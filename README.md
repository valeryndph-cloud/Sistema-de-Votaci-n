
# Sistema de Votación 🗳️

Aplicación web desarrollada en Python (Flask) para gestionar votaciones de manera sencilla, segura y colaborativa.

## 🚀 Funcionalidades y Autores

El proyecto fue desarrollado en equipo, dividiendo las responsabilidades en las siguientes 3 funciones principales:

1. **Gestión de Base de Datos y Registro** (`database.py` / `app.py`)

   - **Descripción:** Configuración de la base de datos, almacenamiento seguro de usuarios y registro de votos.
   - **Autor:** *(Ximena Jimenez)*
2. **Módulo de Autenticación y Login** (`login.html`, `login.js`, `login.css`)

   - **Descripción:** Interfaz y lógica para el inicio de sesión de los usuarios, garantizando el acceso seguro al sistema de votación.
   - **Autor:** *(Valerryn Perea)*
3. **Cálculo y Visualización del Ganador** (`app.py` / mejoras de equipo)

   - **Descripción:** Lógica implementada para procesar los votos emitidos, determinar la opción ganadora y mostrarla al finalizar la votación.
   - **Autor:** *(Alejandro Varela y Juliana Betancur)*
